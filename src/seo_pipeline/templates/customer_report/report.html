Data sources & metric definitions

Google Search Console supplies first-party clicks, impressions, click-through rate (CTR), and average search position. CTR is clicks divided by impressions. Lower position numbers are better. CTR changes are percentage points (pp).

OpenSEO supplies estimated organic traffic and keyword visibility, plus observed backlink counts. Estimated traffic is not measured visits or Search Console clicks. Live estimates are labeled with their observation date and are not historical monthly totals. Missing values mean Not available, not zero.

Search Console scope: {{ s.site.search.device }} devices; {{ s.site.search.gsc_country or 'all countries' }}; web search. Provider keyword market: {{ s.site.search.country }} / {{ s.site.search.language }}. Query totals can exclude anonymized searches. Changes compare periods of different calendar lengths without daily normalization.

Keyword new/lost counts require complete comparable lists; bounded samples do not prove absence. {% if not s.collection.keywords_complete %}The keyword collection is unavailable or incomplete.{% endif %}
